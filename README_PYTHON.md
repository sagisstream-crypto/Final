# ShelfScan (Python) — пошаговый запуск

Python-версия сканера «тихая полка → вынос». Работает как отдельный фоновый
процесс (не зависит от открытой вкладки браузера), подписывается на **настоящие**
минутные свечи Binance (`kline_1m`) в дополнение к 15-минутным, и отдаёт тот же
дашборд, что и `shelf-scanner.html`, только через локальный веб-сервер.

Модель и пороги идентичны HTML-версии — счёт сверен с оригиналом исследования
до 3.4×10⁻⁵ (см. раздел «Проверка» ниже). Если вам не нужна круглосуточная
работа без браузера — HTML-версия (`shelf-scanner.html`) проще: два клика,
без установки Python.

---

## Обновили файлы, а ничего не изменилось? Перезапустите процесс

**Это отличается от HTML-версии.** Обновление `shelf-scanner.html` подхватывается
простым обновлением страницы в браузере (F5). Python-версия — отдельный
процесс: если он уже запущен, обновление `app.py`/`model.py`/`dashboard.html`
на диске **ничего не изменит**, пока вы не остановите старый процесс и не
запустите его заново. Браузерная вкладка при этом может выглядеть обновлённой
(если вы её перезагрузили) — но она просто опрашивает всё тот же старый
Python-процесс в фоне, который отдаёт данные по старой логике.

Как проверить, что вы на актуальной версии — вверху дашборда рядом с
названием теперь написано «сборка YYYY-MM-DD...». Если это не совпадает
с тем, что вы ожидали получить после обновления — процесс старый.

**Чтобы обновиться:**
1. Найдите чёрное окно консоли, в котором работает сканер, и полностью
   закройте его (или нажмите в нём `Ctrl+C`, дождитесь остановки).
2. Убедитесь, что новые файлы (`app.py`, `model.py`, `dashboard.html`)
   заменили старые в папке `pyscanner` (при распаковке архива поверх —
   так и происходит; если распаковывали в новую папку — запускайте из неё).
3. Запустите `run_windows.bat` заново.
4. Обновите страницу в браузере (F5) — в шапке должна появиться новая сборка.

## Windows — шаг за шагом

**1. Установите Python**, если его ещё нет.

- Откройте https://www.python.org/downloads/
- Скачайте последнюю версию (3.11 или новее) и запустите установщик.
- **Важно:** на первом экране установщика отметьте галочку
  **«Add python.exe to PATH»** внизу окна — без неё команда `python` не будет
  работать из командной строки.
- Нажмите «Install Now» и дождитесь завершения.

**2. Скачайте папку `pyscanner`** из этого репозитория к себе на компьютер
(например, на Рабочий стол).

**3. Запустите сканер.**

- Откройте папку `pyscanner` в проводнике.
- Дважды кликните на `run_windows.bat`.
- Откроется чёрное окно консоли: оно само поставит нужную библиотеку
  (`aiohttp`) и запустит сканер. При первом запуске команда
  `pip install` попросит немного подождать.
- Браузер откроется автоматически на `http://localhost:8765`. Если не
  открылся — откройте эту ссылку вручную в любом браузере.
- **Окно консоли должно оставаться открытым** — в нём работает сканер.
  Свернуть можно, закрывать нельзя.

**4. Дождитесь загрузки истории.** На вкладке «Радар» будет счётчик вида
«гружу историю · 120/480» — это 1–2 минуты, дальше сканер работает сам.

**5. Настройте Telegram** (по желанию) — вкладка «Настройки», как в HTML-версии:
создайте бота у `@BotFather`, узнайте свой chat id у `@userinfobot`, вставьте
оба значения, включите галочку и нажмите «отправить тестовое».

**Чтобы остановить** — закройте окно консоли или нажмите в нём `Ctrl+C`.

**Чтобы запустить снова** — просто ещё раз дважды кликните `run_windows.bat`.
Настройки и история сигналов сохраняются в `pyscanner/data/` и никуда не денутся.

### Автозапуск при включении компьютера (опционально)

Если хотите, чтобы сканер поднимался сам при старте Windows:

1. Нажмите `Win+R`, введите `shell:startup`, нажмите Enter — откроется папка автозагрузки.
2. Создайте в ней ярлык на файл `run_windows.bat`.

Учтите: консольное окно будет появляться при каждом входе в систему —
это ограничение простого `.bat`-запуска. Для полностью бесшумной фоновой
службы на Windows нужен дополнительный инструмент (например, NSSM) —
скажите, если такой вариант нужен, распишу отдельно.

## macOS / Linux — шаг за шагом

```bash
# 1. Python 3.9+ обычно уже установлен. Проверить:
python3 --version

# 2. Перейти в папку pyscanner (после скачивания репозитория)
cd pyscanner

# 3. Запустить
./run_mac_linux.sh
```

Откроется `http://localhost:8765` в браузере. Для остановки — `Ctrl+C` в терминале.

Для автозапуска на Linux — юнит `systemd --user`, на macOS — `launchd`;
скажите, если нужно, соберу конфиг под вашу систему.

## Что видно на дашборде

То же самое, что в HTML-версии: вкладки Радар / Сигналы / Настройки / Модель,
колонка «готов», пульс в шапке, карточка «Диагностика».

**Одно новое поле** — в карточке каждого сигнала и в Telegram-сообщении
появляется строка «набор объёма: рывком / накоплением», посчитанная по
настоящим минутным свечам внутри выносного бара. Это **справочная информация**,
не входит в score — проверено на 1551 реальном сигнале, что добавление этой
структуры в модель ухудшает точность (AUC 0.849→0.815, переобучение на малой
выборке). Подробности — на вкладке «Модель» в самом дашборде.

## Структура файлов

```
pyscanner/
  app.py              — движок: Binance REST/WS, модель, веб-сервер, Telegram
  model.py             — признаки и коэффициенты модели (сверено с исследованием)
  dashboard.html       — фронтенд (тот же визуальный стиль, что shelf-scanner.html)
  requirements.txt     — единственная зависимость: aiohttp
  run_windows.bat       — запуск в один клик на Windows
  run_mac_linux.sh      — запуск в один клик на macOS/Linux
  data/                 — тут появятся config.json, signals.json, scanner.log
                          после первого запуска (не входит в репозиторий)
```

## Ошибка сертификата в Telegram/Binance (антивирус подменяет TLS)

Если при нажатии «отправить тестовое» или в журнале видите что-то вроде

```
Cannot connect to host api.telegram.org:443 ssl:True
[SSLCertVerificationError: ... self-signed certificate in certificate chain]
```

— это не баг сканера. Антивирус (чаще всего Kaspersky, реже ESET и похожие)
или корпоративный прокси проверяет ваш HTTPS-трафик и подменяет сертификат
на свой. Браузер доверяет этому подменённому сертификату автоматически —
он давно занесён в системное хранилище Windows. Python по умолчанию смотрит
в собственный, отдельный список доверенных сертификатов, который про
антивирус ничего не знает, поэтому и падает именно Python-скрипт, хотя
тот же `api.telegram.org` прекрасно открывается в браузере.

**Уже исправлено начиная с этой версии**: сканер использует пакет
`truststore`, который заставляет Python брать сертификаты из того же
системного хранилища, что и браузер. Если вы обновили `pyscanner` из
архива/репозитория заново — достаточно один раз выполнить
`pip install -r requirements.txt` (или просто снова запустить
`run_windows.bat`, он это сделает сам) и перезапустить сканер.

Если ошибка всё равно повторяется — в журнале («Настройки» → «Журнал»)
будет строка «truststore не подключён». Тогда:

1. Проверьте версию Python: `python --version` — нужна 3.10 или новее.
2. Временно отключите проверку зашифрованных соединений в антивирусе
   (обычно называется «Проверка защищённых соединений» / «Сканирование
   SSL/TLS») и попробуйте снова — это подтвердит диагноз.
3. Если проблема осталась — напишите, какой у вас антивирус, разберём точечно.

## Частые проблемы

**«Python не найден»** при запуске `.bat` — Python не в PATH. Переустановите
Python с python.org, не забыв галочку «Add python.exe to PATH».

**Порт 8765 занят** — измените `HTTP_PORT = 8765` в начале `app.py` на
свободный, например `8766`, и открывайте `http://localhost:8766`.

**«Бэкенд недоступен»** на странице — окно консоли с `python app.py`
закрыто или упало с ошибкой. Посмотрите текст ошибки в консоли или в
`pyscanner/data/scanner.log`.

**Изменил оборот/потолок пар в настройках, но список не меняется** — эти
два параметра требуют перезапуска (`app.py` строит вотчлист один раз при
старте). Дашборд покажет жёлтую плашку с напоминанием; закройте консоль
и запустите `run_windows.bat` снова.
