# onchain-radar

Ончейн-сканер накопления по ERC-20 токенам: следит за net-flow с бирж, DEX
buy/sell и повторными покупками крупных кошельков, комбинирует это в score
0–100 и шлёт карточку сигнала (консоль + опционально Telegram-бот), когда
несколько независимых признаков совпадают.

Не клон конкретного платного продукта — независимая реализация того же
класса сигнала (ончейн-накопление до движения цены) на публичных бесплатных
источниках: [Etherscan V2 API](https://docs.etherscan.io/etherscan-v2) для
переводов токена/балансов и [DexScreener](https://docs.dexscreener.com/api/reference)
для цены/ликвидности/DEX-объёма.

## Важно: чего тут нет

- **"Smart Money"-разметки кошельков нет.** Платные сервисы вроде Arkham
  ($1500/мес за нужный уровень API) продают проприетарные ярлыки "кошелёк с
  историей удачных ранних входов". Здесь вместо этого — прозрачная эвристика:
  крупные переводы (≥ `largeTransferUsdMin`, по умолчанию $5000) на адреса,
  которые не являются известной биржей/пулом, плюс повторные покупки одним
  адресом в окне.
- **Адреса бирж вы вписываете сами.** `src/knownExchangeWallets.js` — пустой
  каркас. Не стал подставлять адреса горячих кошельков бирж по памяти: одна
  ошибка в hex-адресе даёт тихо неверный сигнал, а не сигнал послабее. Берите
  адреса из проверяемого источника (ярлык прямо на etherscan.io/arbiscan.io,
  публичный reference-список, Nansen/Arkham entity pages) — формат см. в файле.
- **Live-интеграция не проверена в этой среде.** `api.etherscan.io` и
  `api.dexscreener.com` заблокированы политикой egress-прокси текущей
  песочницы (то же самое, что не пускает и на `t.me`) — проверить реальные
  HTTP-запросы отсюда не вышло. Проверено только через `npm test` — чистая
  логика скоринга (`src/score.js`) на синтетических данных, 6/6 зелёных.
  Запускайте на машине с обычным доступом в интернет (свой ноут, VPS) и
  проверьте первый прогон глазами, прежде чем доверять сигналам.

## Установка

```bash
cd onchain-radar
cp .env.example .env
```

Заполните `.env`:
- `ETHERSCAN_API_KEY` — бесплатный ключ с https://etherscan.io/apis. С 2024
  один ключ работает сразу на Ethereum, Arbitrum и остальных поддерживаемых
  EVM-сетях через Etherscan V2 (`chainid` в запросе), отдельный ключ на
  каждую сеть не нужен.
- `WATCHLIST` — список токенов через запятую в формате `chainId:0xАдрес`.
- `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` — опционально, если хотите
  получать карточки сигналов в Telegram. Бота создаёте сами через
  [@BotFather](https://t.me/BotFather), `chat_id` — свой (узнать через
  [@userinfobot](https://t.me/userinfobot)) или канала, куда бот добавлен
  админом.

Впишите адреса бирж в `src/knownExchangeWallets.js` (см. комментарий в файле)
— без них net-flow с бирж всегда будет нулевым и score будет занижен.

## Запуск

```bash
npm start
```

Опрашивает `WATCHLIST` каждые `POLL_INTERVAL_MS` (по умолчанию 5 мин),
печатает карточку в консоль и дописывает `data/signals.jsonl`, когда
score токена проходит порог (`SCORE_ALERT_THRESHOLD` = 55 в `src/alerts.js`)
и токен не в кулдауне (6ч — это ончейн-накопление, не минутный скальп).

## Тесты

```bash
npm test
```

Только чистая логика (`analyzeTransfers`, `computeAccumulationScore`) на
синтетических данных — без сети.

## Как это устроено

1. `src/watcher.js` берёт лучшую по ликвидности DEX-пару токена
   (DexScreener) и последние ~200 ERC-20 Transfer-событий по контракту
   (Etherscan).
2. `src/score.js` размечает переводы: вывод/занос на известные биржи,
   крупные переводы на новые/повторные некэксчейндж-адреса — и считает
   0–100 score с разбивкой по причинам (как `computeScore()` в
   `../index.html`, тот же принцип: сумма взвешенных компонентов, зажатая
   в диапазон).
3. `src/alerts.js` форматирует карточку, пишет журнал, шлёт в Telegram
   при заполненных `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID`.

## Известные ограничения

- Etherscan free tier — грубо 5 запросов/сек и не даёт полный список
  холдеров токена (`tokenholderlist` практически бесполезен без Pro), поэтому
  здесь нет метрики "% изменения баланса топ-100 холдеров за 7 дней" — это
  расширение под Etherscan Pro, а не то, что можно честно посчитать бесплатно.
- DEX buy/sell берётся из `txns.h24` DexScreener — это счётчик сделок, не
  объём по стороне (free API объём по покупкам/продажам отдельно не отдаёт).
- Список известных бирж/пулов, который вы заполните, по построению никогда
  не будет исчерпывающим — новые биржевые кошельки появляются постоянно.
