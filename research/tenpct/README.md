# «+10% раньше −10%» на альтах Binance

Вопрос: есть ли закономерность, по которой заранее видно, куда цена альта пройдёт 10% — вверх или вниз?

Данные: 1205 альт-пар (spot + USDT-M, вкл. делистнутые), окт 2025 – 28 сен 2026, 5m-свечи; фандинг, премиум-индекс,
открытый интерес. Всё лежит в ветке `market-data` этого репозитория.
Разметка (`lab10.py`): вход по закрытию часа, что раньше заденется по 5m-свечам: +10% или −10% (лимит 14 дней;
оба в одной свече = проигрыш). Подбор — окт–апр, проверка — май–сен. Средний уровень без правил: 49.7% вверх / 50.3% вниз.

## Что сработало (оба — ШОРТ фьючерса)

| правило | файл | подбор: сделок / −10% первым | проверка: сделок / −10% первым | EV/сделка после фандинга (подбор / проверка) |
|---|---|---|---|---|
| Фандинг < −0.98% (на 8ч) и 24ч-волатильность < 5%/ч | `d_best.py` | 1108 / **65.2%** | 482 / **65.0%** | +1.07% / +1.16% |
| Фьючерс дешевле спота: средний премиум за 24ч < −0.6% | `l_best.py` | 1736 / 59.8% | 1002 / 58.9% | +0.34% / +0.49% |

Проверка по месяцам (фандинг-правило): май 74.6%, июн 73.3%, июл 69.5%, авг 60.9%, **сен 43.5%** — слабеет.
Шорт при отрицательном фандинге платит фандинг: ≈1.1–1.8% за сделку (медиана удержания ≈16ч), это уже вычтено в последней колонке.

## Что не сработало
- Технический анализ (50 признаков: тренды, пробои, откаты, сжатие волатильности, объёмы) — `t_*.py`: 56–60% на подборе → ≈51% на проверке.
- Жизненный цикл (новые листинги, откат после пампов, отскок после краша, сила к рынку, режим BTC) — повторяет рынок, не стабильно.
- Машинное обучение (LightGBM, 55 признаков, `m_*.py`): AUC на проверке 0.4995 — направление 10%-хода по цене/объёму не предсказуемо.
  Главный драйвер — режим рынка на ближайшие 1–14 дней.

## Запуск
`lab10.py` строит `h10/` из 5m-свечей (SRC = папка с `{mkt}_{SYM}.parquet`). `d_best.py` ждёт фандинг в `data_extra_d/`
(в ветке market-data: `futures/funding` и `futures/funding_sep`, файлы `fund_*.parquet`, `fundsep_*.parquet`).
