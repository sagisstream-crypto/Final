# Исследование индикатора «Вынос»

## Как проверить самому

```bash
pip install pandas numpy pyarrow
python backtest_vynos.py                 # год, ВСЕ альт-пары Binance (вкл. делистнутые), $10k, 1%/сделку
python backtest_vynos.py --help          # капитал, размер, слоты, проскальзывание, период, рынок
```
Скрипт сам качает свечи с data.binance.vision (без ключей; ~1 ГБ, первый запуск 30–60 мин, дальше из кеша)
и пишет `vynos_result/all_signals.csv`, `portfolio_trades.csv`, `equity.csv`.

# Первая версия (март–сентябрь 2026, 155 пар)

Как найден и проверен сигнал из `vynos.html` / `vynos-core.js`.

## Данные
5m-свечи Binance (архив data.binance.vision), март – 28 сентября 2026, 155 альт-пар (~90 spot + ~65 USDT-M).
Исключены BTC, ETH, BNB, SOL, XRP, DOGE, ADA, TRX, TON, LINK, AVAX, LTC, BCH, DOT, XLM, SHIB, HBAR, SUI, UNI, NEAR, APT, ICP, ETC, FIL, ATOM и стейблы.

```bash
pip install pandas numpy pyarrow
python dl.py        # мар–авг → data/
python dl_hold.py   # сентябрь (holdout) → data_hold/
python hold.py      # прогон финального сигнала на сентябре
python parity_py.py && node parity.js parity.json   # JS-ядро == Python, свеча в свечу
```

## Правила бэктеста (`lib.py`)
Сигнал на закрытии бара → вход по открытию следующего. TP и SL в одной свече = стоп. Комиссия 0.1% round-trip.
Сделки по одной паре не перекрываются. Подбор параметров — только мар–июн; июл–авг — вне выборки; сентябрь — скачан после
того, как правила были зафиксированы.

## Результаты (финальный сигнал, `vynos_signal.py`, только LONG)

| период | сделок | winrate | EV/сделка | spot | fut |
|---|---|---|---|---|---|
| мар–июн (подбор) | 643 | 83.7% | +0.41% | 84.0% | 83.3% |
| июл–авг (вне выборки) | 303 | 78.2% | +0.18% | 76.8% | 80.5% |
| 1–28 сен (holdout) | 315 | 77.5% | +0.29% | 76.4% | 78.5% |

Сентябрь: сигналы в 26 днях из 28, top-5 пар = 35% прибыли, 78% пар в плюсе.

## Что проверили и отбросили
- Наивный вынос (прокол лоя/хая + объём + возврат), `h_sweep.py`: EV < 0 после комиссий при любых TP/SL.
- Отскок после общерыночного пролива, `rejected_market_flush.py`: 72% вне выборки, но в сентябре 61% и EV −0.08%.
- Торговля по направлению импульса / шорт выдохшегося пампа, `rejected_ignition_fade.py`: вне выборки EV −0.14% (фьючерсные шорты сливают на гипер-волатильных парах).
- Шорт-зеркало выноса хая: прибыль держится на нескольких пампящихся монетах, не устойчиво.

## Риски
- Средний выигрыш ≈ +1%, проигрыш ≈ −2.8%. Безубыточность при winrate ≈ 74%, запас небольшой.
- Проскальзывание не моделировалось: +0.1% издержек на сделку снижают EV примерно до +0.1–0.2%.
- Фильтр «с 12:00 UTC» был добавлен после одного взгляда на июль–август; сентябрь это не опроверг, но выборка всё ещё ~1 месяц.
