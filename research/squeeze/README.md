# Шорт-сквиз на альтах Binance USDT-M (окт 2025 – сен 2026)

Прокси «short interest» в крипте: отрицательный фандинг, соотношение лонг/шорт аккаунтов (global L/S),
позиции топ-трейдеров, рост открытого интереса (OI) на падении. Фандинг — по всем 785 перпам, L/S и OI — по ~80 ликвидным.
Данные — ветка `market-data`. `d_feat.py` → признаки, `sq_panel.py` → исходы вперёд, `sq_study.py` / `sq_reverse.py` / `sq_momo.py` — таблицы.
Только часы с оборотом ≥ $1M/сутки; события — не чаще раза в 24ч на монету. win10 = % случаев «+10% раньше −10%» среди разрешившихся.

## 1. Много шортов → цена обычно продолжает падать
| условие | подбор: ср. 24ч / +10% за 24ч / −10% за 24ч / win10 | проверка |
|---|---|---|
| все часы | −0.56% / 12.8% / 10.4% / 45.8% | −0.15% / 10.8% / 7.9% / 52.9% |
| фандинг < −0.1% | −1.53% / 21.6% / 20.6% / 44.5% | −1.78% / 23.1% / 22.4% / 46.2% |
| фандинг < −0.3% | −2.99% / 26.3% / 30.3% / 41.5% | −3.33% / 27.7% / 31.3% / 42.3% |
| фандинг < −1% | −5.46% / 33.4% / 45.3% / 38.4% | −5.80% / 31.9% / 47.5% / 37.8% |

Отрицательный фандинг в 2–3 раза повышает шанс резкого выноса вверх, но шанс обвала растёт ещё сильнее.

## 2. Настоящие сквизы (+15% за 24ч и OI −10%) — ≈1% часов
Условия повышают шанс сквиза в 4–18 раз (фандинг < −0.3%: 8–12% против 0.7–1.3%), но в тех же условиях
шанс −15% за 24ч — 28–34%. Типичный профиль ДО сквиза: монета уже растёт (+3.8% за 24ч, +11.7% за 72ч),
OI растёт, шорт-аккаунтов больше, чем лонг, волатильность в 4 раза выше обычной; фандинг — обычный.

## 3. Рост + толпа в шорте → продолжение вверх (LONG)
| условие | подбор n / win10 / ср. 24ч | проверка n / win10 / ср. 24ч |
|---|---|---|
| база (перпы с L/S) | — / 49.3% / −0.35% | — / 54.8% / +0.04% |
| рост 72ч > 10%, L/S < 1, OI 72ч > +5% | 572 / **54.7%** / +1.05% | 277 / **60.9%** / +2.00% |
| рост 72ч > 10%, L/S ≥ 1 (толпа в лонге) | 1855 / 44.7% / −0.59% | 1760 / 52.2% / 0.00% |

+5–6 п.п. к базе в обоих периодах, но: ~80 ликвидных перпов, медиана 24ч около нуля, правило сформулировано после
обратного анализа по всему году — нужна проверка на новых данных.
