# Фэнтези-шортсы (5 × 30 c, 1080×1920)

Готовые видео лежат в `out/`:

| Файл | Название | Голос |
|---|---|---|
| `01_dragon.mp4` | Последний дракон | мужской |
| `02_stars.mp4` | Та, что зажигает звёзды | женский |
| `03_knight.mp4` | Рыцарь, который вернулся | мужской |
| `04_forest.mp4` | Дух леса | женский |
| `05_ice.mp4` | Ледяное сердце | женский |

Всё генерируется кодом: нейросетевая озвучка (edge-tts), процедурная музыка (струнный пэд, колокольчики,
хор и удары на кульминации), процедурная графика (параллакс, свечение, частицы, силуэты) и субтитры
с подсветкой текущего слова. События в кадре (трещина яйца, звезда спускается, лес засиял и т.д.)
синхронизированы с таймингом слов в озвучке.

## Пересборка

```bash
pip install numpy scipy pillow imageio-ffmpeg edge-tts
python3 render.py 01_dragon            # одно видео -> out/01_dragon.mp4
python3 render.py 01_dragon --preview  # несколько кадров в build/preview
```

Тексты — в `stories.py`, сцены — в `scenes.py`, музыка — в `music.py`.
