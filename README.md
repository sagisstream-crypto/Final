# ShelfScan + VolScan

Сканеры Binance. VolScan и ShelfScan — по одному HTML-файлу без сборки и сервера. ShelfScan есть и как Python-версия (`pyscanner/`) — фоновый процесс с локальным дашбордом.

## `shelf-scanner.html` — тихая полка → вынос

Ищет паттерн: монета стоит в узком тихом коридоре, затем взрывается объём
и цена выходит из него.

Внутри — модель, обученная на **годе 15-минутных свечей по 833 бессрочным
USDT-M фьючерсам** (24.5 млн баров), с проверкой на отложенном периоде
и барьерным тестом по минутному пути. Полный отчёт: **[RESEARCH.md](RESEARCH.md)**.

Коротко, что даёт модель (все цифры — out-of-time):

| score | алертов/сутки по рынку | P(+10% за 2ч) | P(+40%) | поймано выносов |
|---|---|---|---|---|
| без модели | 51.6 | 6.3% | 0.28% | 47.9% |
| **≥ 0.10** | **13.3** | **20.8%** | **1.09%** | **47.9%** |
| ≥ 0.30 | 2.4 | 35.1% | 5.30% | 35.7% |

Порог 0.10 срезает три четверти алертов, не потеряв ни одного выноса.

**Что нужно знать до использования.** Перебрано 1240 конфигураций входа
и выхода на 7612 walk-forward сигналах с точным минутным путём. Значимо
прибыльных после поправки на множественные сравнения — **ноль**.

Причина найдена и она содержательная: **score предсказывает размах движения,
а не его направление**. Медианный ход вверх и вниз растут с ростом score
синхронно (при score ≥ 0.30 это +10.5% и −13.6% за 48ч). Модель хорошо
отвечает на вопрос «где сейчас рванёт» и никак — на вопрос «куда».

Поэтому сканер — инструмент отбора внимания, а не торговый автомат.
Подробности в разделах 6 и 6a [RESEARCH.md](RESEARCH.md) и во вкладке
«Модель» самого сканера.

### Запуск

Нужен https — Binance WebSocket и установка PWA не работают с `file://`.

```bash
python3 -m http.server 8080      # затем http://IP:8080/shelf-scanner.html
```

Или GitHub Pages / Cloudflare Pages / любой nginx с SSL.

### Telegram

1. `@BotFather` → `/newbot` → скопировать токен.
2. `@userinfobot` → узнать свой chat id (для канала — с минусом).
3. Вкладка «Настройки» → вставить, включить, нажать «отправить тестовое».

Токен хранится только в IndexedDB браузера и никуда больше не уходит.

### Вкладки

- **Радар** — вотчлист: кто стоит на полке, у кого пошёл объём, кто выстрелил.
- **Сигналы** — история с уровнями полки и точкой инвалидации.
- **Настройки** — все пороги шлюза, у каждого подсказка с ценой вопроса.
- **Модель** — на чём обучено, калибровка, подбор шлюза, что выучила модель
  и где границы её применимости.

## `index.html` — VolScan Early v15

Прежний сканер объёмных всплесков по споту и USDT-M: IndexedDB вместо
localStorage, корректный уход в фон, нижние вкладки, PWA. Работает
независимо от ShelfScan.

Честный лимит фона: ни один мобильный браузер не даст живому WebSocket
работать часами в свёрнутом виде — iOS убивает JS через секунды.
Приложение сбрасывает базу на диск перед уходом и поднимает сокеты при
возврате, но новые тики в фоне не приходят. Для круглосуточного фона нужен
нативный Android Foreground Service (Capacitor).

### Установка на телефон

**Android (Chrome):** открыть по https → меню → «Установить приложение».
В настройках батареи выставить «без ограничений».

**iPhone (Safari):** Поделиться → «На экран Домой», открывать ярлык,
а не вкладку.

## Python-версия

`pyscanner/` — тот же сканер как фоновый Python-процесс с локальным
веб-дашбордом, не зависящий от открытой вкладки браузера. Дополнительно
подписывается на настоящие минутные свечи Binance (не только форминг-снимки
15-минутного бара) и показывает на карточке сигнала, как именно набирался
объём — рывком за одну минуту или накоплением. Модель и пороги те же самые,
счёт сверен с оригиналом исследования до 3.4×10⁻⁵.

Пошаговый запуск (Windows/macOS/Linux): **[README_PYTHON.md](README_PYTHON.md)**.
